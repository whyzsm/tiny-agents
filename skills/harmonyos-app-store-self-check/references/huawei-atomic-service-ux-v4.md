## 元服务定位 / Product Definition

官方总览将元服务定义为 HarmonyOS 中提供特定服务或功能的平台形态，核心特征是：

- 免安装、轻量快捷、随处可及、即用即走、一步直达；
- 入口包括负一屏、全局搜索、应用市场、小艺建议、桌面，以及应用内调用；
- 也可以通过 HarmonyOS Connect 标签的扫码、“碰一碰”或靠近触达；
- 用户路径应围绕发现、打开、加载、落地页使用和退出构建，不应强行套用完整应用的
  注册、启动开屏和复杂层级流程。

若项目只是普通 HarmonyOS 应用，必须记录 `NOT_APPLICABLE`，不能把元服务专属要求
误当成普通应用的发布阻断项。

## 体验场景 / Experience Scenarios

| 官方场景 | 官方要点 | 自检证据 |
|---|---|---|
| 服务发现 | 线上按用户意图通过负一屏、全局搜索、应用市场、桌面发现；线下通过标签、碰一碰、靠近或扫一扫发现 | 入口清单、页面/设备录屏、服务配置 |
| 服务使用 | 元服务入口 → 启动加载 → 落地页使用 → 退出；服务状态可在锁屏、实况窗、负一屏更新；服务消息可在负一屏查看 | 当前包操作记录、加载/退出和状态触达证据 |
| 服务管理 | 可在桌面、负一屏、应用市场、元服务等场景添加、收藏、移除 | 当前包管理操作记录 |
| 服务分享 | 元服务和服务卡片支持近场/远场分享；接收方可无需安装直接打开，或添加到负一屏/桌面 | 分享链路、接收设备和无安装打开记录 |

## 基本要素 / Basic Elements

### 基础信息

- 每个元服务拥有独立的图标和名称；名称应准确、简短、易懂、易记，官方建议不超过
  `8` 个中文字符。
- 元服务图标区别于应用图标，使用元服务图标生成工具或符合其设计语言的资源。
- 上传方形资源支持 `.png`、`.jpeg`、`.jpg`，尺寸为 `1024 x 1024 px`，背景不透明，
  内容清晰，无模糊、锯齿、拉伸；主体元素建议占资源约 `77%`。
- 不使用可能误导用户的红点、`HOT` 等运营标记；同一开发者的多个元服务应可区分，
  避免复用相同图标；外圈线和中心圆需要在黑白背景上保持清晰。

### 服务卡片

每个元服务可以配置服务卡片。卡片是元服务的轻量承载，应做到易用可见、智能可选、
多端可变。自检要确认卡片展示内容与元服务真实能力一致，并在适用设备和入口下验证
卡片的打开、更新、空/错误状态。

## 设计原则 / Design Principles

官方原则为：`通用友好`、`轻量高效`、`简洁高级`、`安全可靠`。

### 通用友好

- 无开屏、无广告干扰、无重复加载；进入启动界面只有一个加载过程。
- 首次进入应支持一键完成隐私声明和用户协议同意；使用华为账号统一授权能力；支持
  通过系统返回或关闭一键退出，不用二次弹框打断。
- 单页面主要信息层级不超过 `3` 层，减少嵌套和不必要跳转。
- 动效应自然流畅，无抖动、卡顿、闪跳；操作反馈即时可控。

### 轻量高效

- 导航路径清晰；次级页面返回统一为返回上一层。
- 元服务标题栏右侧由系统统一放置元服务胶囊（Menubar），开发者必须避让该区域，
  胶囊左侧不要放功能图标。
- 一级页面底部页签建议使用 `AtomicServiceTabs`，数量不少于 `2` 且不超过 `5`；
  运营图标最多一个，页签为单数时放在中间位置。
- 核心功能关键操作应在首屏可发现；错误要给出解决方案；等待操作提供暂停或取消；
  使用自然语言，避免技术术语和诱导性运营文案。

### 简洁高级

- 保持图形、尺寸、间距、文本和页面视觉平衡；用层级和对比突出重点，控制信息密度。
- 避免无关广告干扰；图片清晰，图标表意清楚、风格一致，单个界面最多使用两种图标
  风格；相同场景保持布局、颜色、材质和字体一致。

### 安全可靠

- 收集个人数据时清晰说明用途；权限授权、账号授权可控制、可反悔。
- 优先使用系统提供的安全控件和系统选择器处理位置、剪贴板、保存、图库、文件、
  联系人、扫一扫、相机等敏感场景，避免自建不可控的数据获取路径。
- 涉及账号时按华为账号规范实现静默登录。元服务不得自建登录页，不应直接使用“注册、
  登录、退出登录、注销账号”等容易误导的通用文案；如提供开发者账号注销，应明确
  注销对象。
- 不应在用户刚进入、尚未产生浏览或业务意图时弹出手机号授权；账号和个人信息授权
  应在真实业务意图发生时申请。

## 本地门禁映射 / Local Gate Mapping

以下是本 Skill 的本地检查 ID，不是华为官方编号：

| ID | 检查 | 最低证据 | 默认影响 |
|---|---|---|---|
| `ATOMIC-1` | 识别项目是否为元服务；普通应用明确记录不适用 | module/product 配置、发布形态、产品说明 | `P1`：范围无法确认 |
| `ATOMIC-2` | 服务发现入口和一步直达链路可达 | 入口清单、设备/页面记录 | `P1`：核心入口不可用 |
| `ATOMIC-3` | 无开屏、无重复加载、启动/落地页/退出链路清晰 | 当前包录屏或设备记录 | `P1`/`P2` |
| `ATOMIC-4` | 名称、元服务图标、卡片与真实能力一致 | 资源、服务配置、截图 | `P1` |
| `ATOMIC-5` | 元服务胶囊、标题栏和底部页签适配 | 设备截图、操作记录 | `P1` |
| `ATOMIC-6` | 华为账号静默登录、隐私/权限授权和撤回符合范围 | 授权链路、隐私材料、设备记录 | `P0`/`P1` |
| `ATOMIC-7` | 服务状态、消息、添加/收藏/移除可用 | 系统入口和当前包操作记录 | `P1` |
| `ATOMIC-8` | 近场/远场分享，接收方无安装打开或添加链路 | 两端设备记录 | `P1`/`UNVERIFIED` |
| `ATOMIC-9` | 等待、失败、取消、重试和自然语言反馈完整 | 页面状态截图、设备记录 | `P1`/`P2` |

静态配置只能确认声明和资源存在，不能证明元服务入口、胶囊、卡片、静默登录、分享
和系统级状态已经在设备上正常运行。缺少当前版本设备证据时记为 `UNVERIFIED`，
不要把普通应用 AGC 的 `UX` 通过复制为元服务通过。
